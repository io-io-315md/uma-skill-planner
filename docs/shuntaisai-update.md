# 駿大祭への更新（2026-10-28）

## 本育成と固定枠

本育成は「朋、史解き ―午式駿大祭―」を基準とし、6枠目をSSR吾妻［いとどめでたき、まつりかな］（30323）へ変更。5枠目の内部レンタル位置は維持し、自前・レンタルの表記は出さない。旧保存の6枠目のたづなを吾妻へ置き換え、他5枚・赤因子・準備記録・保存スナップショットを保持する。自動編成は従来どおり起動・キャラ・脚質・レース変更時に再適用。

ルネの実装後の編成例とNeko長明の公開noteを照合し、スピード2・スタミナ1・パワー1・賢さ1・友人1の5種類を基本にする。前シナリオのスピード3枚型は初期案に使わない。

マヤノ［Time of Departure］（30322）は汎用候補。金は「英俊豪傑」＋「機転／希代の才覚／アドバンテージ」の1択。中距離は機転、長距離は希代を基本とし、距離外の金を同時に取得扱いにしない。前方条件は正式な脚質限定と混同せず、候補絞り込みでは後方にも残す。初期案では差しのデジタル、追込のドゥラメンテなど、脚質に合う金の取得を優先して比較する。マヤノが後方で使えない・育成性能が必ず劣るという判断ではない。

## スキルと因子

新カード3枚と新衣装ダスカを追加し、既存パワードゥラメンテのイベントも照合。画像は既存と同じゲーム内顔アイコン・個別カード画像。GameTora個別ページの復元済み日本版イベントから選択肢を取り込み、成功・通常結果で共通するスキルだけを確定した経路として登録する。カードのイベント発生・完走を保証しない。

新しい金と下位白の接続はGameToraのversionsでも補完。マヤノの金から「直感力」などの白を取れる場合は因子の不足から外す。吾妻の神速、お出かけ・白イベント、マヤノ2回目のアオハル点火・賢も照合する。金と引き換えの白択を本育成へ加算する既存の制限は維持。

駿大祭の「本番前のひと時」は選択した1種類だけを計上する。前方ではマヤノ、後方では吾妻を自動択の基本とし、手動変更可能。リンク対象を育成またはサポカに編成した場合だけ金、それ以外は白のヒントとする。全身全霊・ハヤテ一文字・機先の勝負・名にし負う夢は、進行・大成功などの条件を満たした際の取得候補として表示。条件未達の育成を保証する判定ではない。

因子周回は駿大祭（吾妻）、旧トレセン軒（たづな）、URA（従来指定のたづな1枠）を選べる。SSR・SR・Rの候補は維持。URAにたづなのシナリオ特効があるという意味ではない。トレセン軒での因子周回を残すことは、Neko長明の10月27日の見解とも整合する。周回の所要時間や最適シナリオは自動比較しない。

真髄・体を継承済み因子から引き継ぐ方針、自制心の今回の優先度、ファンボーナス43%以上・デビュー1着で1,000人以上になる編成の前提は維持。ファン補填だけの序盤GⅡを再追加しない。

## 掲載情報と更新

11月Tierは指定の京都3000mラボ記事を保持し、10月25日のラボとnoteによる新衣装ダスカを追加。実装直後の暫定評価と明示し、旧記事を新シナリオでの実測順位とは扱わない。12月の比較Tierは引き続き保留。

10月26日の公式対戦予定に合わせて11月22日開始、1月東京2400mの確定条件、4月の予定を反映。1月は基本緑と中距離汎用の初期候補を掲載し、主加速・継承の比較は未完了と明記する。未発表の競馬場や距離を作らない。

前シナリオのキャッシュに固定友人がない／異なる場合は新しい編成データとして受け付けず、現行の同梱データへ戻す。サポカの凸数、ステータスの実測比較、勝率の最適化は未評価。推奨順位・優先度は公開情報と取得ルートに基づく編集上の判断。
