# 個体別のサポカ・赤因子と育成準備

> 2026-10-28更新：現在の本育成・駿大祭周回はSSR吾妻固定、旧トレセン軒・URAは従来のたづな1枠です。[現行仕様・出典](shuntaisai-update.md)。以下は導入時の仕様記録で、現在の固定枠・編成はこの更新を優先します。

2026-10-19追加。親2人・祖父母4人のカード6枚を個体別に並べ、同じ欄に完成時に指定する赤因子と目標星数を表示する。既存のツリーと各個体の詳細編集、個別因子ダイアログも引き続き使える。

## たづな1枠と今回の優先度

前版は白スキルの網羅性を優先してシナリオ用友人枠を確保していなかった。新SSR駿川たづな［一杯のノスタルジア］は、トレセン軒でコツ・習得ゲージ・秘訣などに重要なシナリオ効果がある。ユーザー指定により、全周回案の6枠目を自前たづなへ固定し、残り5枚をSSR・SR・Rから提案する。

URAに同じシナリオ特効があるという意味ではない。今回はユーザーが求めた「たづな1枠を想定」の提案条件としてURAにも適用する。旧保存にも正規化を適用し、自動案は署名の更新で再提案。手動案は先頭5枚を保持して不足を再判定する。たづなが他枠にあって移動で空きが出る場合は、元の6枚目をその空きへ移す。原本の保存スナップショットは保持する。

自制心はユーザー指定で2026年11月京都3000mのみ中へ下げる。攻略資料が中と主張したことにはしない。12月は元から中で、右回り・秋ウマ娘・真髄体などの高は維持する。

参照：[4Gamerの先行体験レポート](https://www.4gamer.net/games/414/G041434/20260615028/)、[GameWithのトレセン軒解説](https://gamewith.jp/uma-musume/article/show/561938)。必須のゲーム編成制限と、シナリオ効率を重視した採用判断を区別する。

## 指定する赤因子

初期案はレース距離の赤★3を各個体の目標にする。京都3000m・中山2500mでは長距離。距離Sの継承機会を作るための設計方針で、Sを保証するものではない。

本育成ウマのバ場・作戦の初期適性がA未満なら、必要な補正分を先に割り振る。同種赤の★1/4/7/10で1/2/3/4段階、開始時上限Aとして計算する。初期F/Gは赤を足しても開始時Aにはできないため、未達を明示する。補正用の個体は、その適性が高いウマを優先し、同程度なら祖父母を先に使う。星数は最大3の厳選目標であり、ゲーム内で確定指定できる星数ではない。

赤因子は1個体に1種類。手動設定した赤・星数目標は保持する。画面の星合計と開始時適性は、全個体がその目標通りに用意された場合の試算で、ユーザーの実際の所持因子を確認した値ではない。

各個体を作るときの赤因子も別に説明する。例えば、完成目標は長距離赤でも初期長距離Bなら、その個体の周回で使用する継承元に長距離赤★1以上を準備して開始時Aへ上げる案を表示する。A以上を狙いやすくするための準備であり、低適性で赤を指定する操作自体を不可とする表示ではない。

## 遺伝子の準備

遺伝子は通常のスキル取得とは別の白因子目標として表示し、サポカのスキル網羅件数には加えない。攻略資料では、育成に使う親・祖父母6人の同種赤が合計★6以上で抽選対象、★12以上が確定ラインとされる。ここでは距離★12＋作戦★6を配分の目安とし、両方の遺伝子の獲得を確約しない。

直接親を作る時、画面で指定した祖父母2人はその親の継承元6人の一部となる。表示中2人の目標星数から、残り4人で必要な星数を計算する。配分上両立しない場合は、距離を優先するか祖父母の赤を調整する案内にする。祖父母の個体を作る周回では、その継承元6人はさらに下の世代なので、画面に表示した6個体をそのまま流用する説明にはしない。
