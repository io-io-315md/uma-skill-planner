# 親・祖父母と因子厳選用の網羅編成

2026-10-19確認。結果タブは「継承・白因子」「本育成のスキル」「因子厳選用サポカ編成」。従来の因子別ダイアログは引き続き使用できる。

## 対象と優先順位

本育成で `status === factor` となる白スキル全体を対象にする。別ルートで取得予定のスキル、金スキル、見送り、継承固有は白因子編成の対象に含めない。主役の1スキルだけに加点する従来の個別案とは別の探索。

サポカの候補はSSR・SR・Rすべて。同じキャラの別カードは併用せず、周回キャラ本人のカードも除く。2026-10-19の指定で、新SSRたづなを自前6枠目に固定して他5枚を探索する条件へ変更。トレセン軒のシナリオ効果を考慮する。URAも今回の指定で同じ枠を確保するが、URAでの必須条件とは説明しない。イベント択は排他的に評価し、金と交換する白択も使える。未確認イベントだけの経路はカバー件数・探索得点から除外する。

取得ルートの件数を高→中→低の辞書順で比較するため、低を多数含むカードが高1件より優先されることはない。各優先度で、他の周回が未カバーの種類を先に評価する。同点時は実装日の新しいカードを優先するが、レアリティによる加点はしない。高の取得元をそれぞれ起点に再探索し、カード1枚の交換も試す。網羅性の探索であり、数学的な最適性・習得率・育成性能を保証しない。

6枠を埋めることで対象スキルが増えない場合は自由枠とし、レースボーナス・育成性能に合わせて編集できる。初回提案で真髄の不足が残る場合は、祖父母1人をURAで周回する補完案も比較し、全体のカバー件数が増える場合に採用する。URAを設定した周回だけに真髄・体/力/速の対決イベントを加え、ツリーと取得方法に明示する。手動調整後の再提案では設定した取得方法を保持する。

## 継承ツリーと担当

直接親2人・祖父母4人に別キャラの候補を配置する。育成本人を除き、継承進化を直接親に優先配置。サポカで補えない白因子を自前で取れるウマは祖父母に優先確保し、残りの継承固有を優先度順に配置。例えば差しの連綿が不足する場合、エピファネイアを継承進化目的ではなく白因子用の祖父母として提案する。ツリーに入らない固有は代替候補に残す。足りない枠は自前スキルで不足分を取れる候補を使う。血統相性・共通勝利レースは計算しない。実際の因子を作る前に確認する。

各ノードは6枠の独立した周回プランを持つ。個体別一覧で6枚と赤因子・星目標を表示し、編集では固定たづな以外の5枚を替えられる。高の白因子は取得元がある両親に重ね、残りは取得ルートと担当数を見て中は最大2人、低は1人に割り振る。これは厳選作業を分担する編集方針で、継承率の計算ではない。担当はそのノードの登録済み取得元があるスキルに限る。取得元が足りないものは別枠で残す。

フレンド側は親の片方を指定し、その祖父母2人も同じ枝に含む。代表の衣装・固有と、その3人に用意する白因子を募集条件として表示する。自前側3人の編成で取得元がないものを補完候補として区別する。実際のフレンド因子や所持キャラ・凸数の照合は行っていない。

## 確認したゲームの仕様

- 直接親の固有ヒントは開始時に取得、祖父母の固有は育成中の継承抽選。白因子の継承も抽選。
- 固有因子を持つ殿堂入りウマを作るには★3以上が必要。継承して覚えた他キャラの固有がそのキャラの固有因子として付くわけではない。
- 今回扱うエピファネイア・ステイゴールドの継承進化には、該当衣装の本人所持と育成開始時のヒント取得が必要。祖父母経由を継承進化可と判定しない。レンタルでも本人所持の条件は残る。所持状況を入力していないため、表示は条件付きの準備案。

## 保存・更新

`lineagePlans` を既存のv2保存データに追加し、コース・作戦・本育成衣装ごとに最大30件保存。各ツリーの6周回は `normalizeFarmingProfile` を使う。従来の `farmingPlans` と本育成のサポカ・択・準備チェックから独立する。JSON保存プランとTXTにも編成・担当・フレンド側を含める。

自動案は本育成のサポカ・択・見送りなどの変更時に再計算する。手動編集した案は変更後も保持し、現在の不足に対するカバー件数を再計算して更新案内を表示。再提案は親・祖父母の配置を保持し、「親・祖父母も選び直す」では配置も初期提案に戻す。周回ウマ変更時には、そのキャラに合うサポカ案を作り直す。
