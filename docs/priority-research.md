# 取得優先度の調査

確認日：2026年10月18日。対象は2026年11月京都芝3000m LoHと12月中山芝2500mチャンミ。

## 分類

取得優先度は「高・中・低」の3段階。公式の順位ではなく、攻略資料・効果・発動条件を照合した本アプリの編集上の判断。発動率・勝率のシミュレーションは行っていない。

編成を固定したnoteの「因子周回優先度」は、編成から取れるスキルを除いている場合がある。本アプリではスキルの取得優先度を先に判定し、その後に選択されたキャラ・サポート・イベント択との不足分を因子候補にする。

## 主な反映内容

| 対象 | 優先度 | 判断理由 |
| --- | --- | --- |
| 右回り○、京都の秋ウマ娘○、中山の冬ウマ娘○ | 高 | 条件が確定したスピード緑 |
| レースの真髄・体 | 高 | 終盤速度の重要候補。持久力2%消費を含めて走り切れる構成が前提 |
| 京都／中山レース場○、非根幹距離○ | 低 | スタミナ補強。必要な持久力が不足する場合は個別に検討 |
| 自制心 | 京都は高、中山は中 | 長距離の掛かり対策。LoHの安定性を重視。掛かりを完全に防ぐものではない |
| 真髄・力 | 差し・追込は中、逃げ・先行は低 | 最終盤に追い越し対象がいる条件を踏まえる |
| 下り坂巧者 | 京都は低、中山は中 | 下り坂の位置と加速区間の重なりを踏まえる |

真髄・体はURA因子だけに限定していない。パワーSSRファインモーションの詳細イベントでは、金2種の択と白3種の択が排他になる。本育成では金側を使うため真髄・体の不足を消さず、因子周回の編成だけで白3種の2択目を取得経路へ計上する。覚醒スキルは各キャラの最大Lvまで計上する。
