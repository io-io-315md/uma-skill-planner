# 因子厳選のローテと育成用赤因子

確認日：2026-10-21。

## データ

GameToraの日本版公開マニフェストの`races`、`ura-races`、`ura-objectives`、`race-fans`を取得。404開催枠と135キャラの育成目標を正規化し、既存271衣装すべてをキャラIDで対応させた。実際に出走する年月はゲーム内日程を使い、実競馬の開催日は転用しない。同名GⅠのコース違い・複数年開催は共通勝利では同じ種類にまとめる。

生成物は`dist/race-data.js`。`node tools/build-race-data.mjs --download`で元データを再取得・再生成できる。マニフェストの各ハッシュを生成物へ記録する。目標分岐の意味を含め、更新時には資料を再確認する。

## 出走・分岐

予約する任意レース、自動の育成目標、選択する分岐目標、抽選・条件付きの目標を別表示する。目標と同じターンへ任意レースを二重予約しない。選択式は推奨する目標レースを明示し、実際に違う目標が表示された場合はポップアップ内で変更・保存できる。

フジキセキは三冠路線（日本ダービー＋菊花賞）とマイル路線（NHKマイルC＋マイルCS）を連動させる。マチカネフクキタルの第2・第7目標は選べる分岐とは扱わず、抽選結果へ合わせる。条件付き目標は、目標にならなかった場合の予約も案内する。ファン数は、ユーザー指定の「デビュー1着時点で1,000人以上を確保できる編成」を前提にする。デビューの基礎ファン700人に対し、合計ファン数ボーナス43%で1,001人となり、阪神JF・朝日杯FS・ホープフルS・全日本ジュニア優駿の出走条件1,000人を満たす。凸数・レベルの入力はないためカードごとの実値を推定せず、全レースの予定1着ファン数を下限の43%で計算する。デビュー後の1,000人不足を理由とするGⅡは追加しない。キャラ固有のGⅡ目標や、別のファン数・着順・回数目標を達成するために本当に必要なレースは残す。

アルダンの菊花賞／秋天と、ファインモーションの最終4目標も選択式として扱う。カレンブーケドールは日経賞ルートを選んだ場合のみ、春天を自動目標へ追加。京都記念ルートで春天を走る場合は任意予約として表示する。

## 赤因子

完成時に狙う赤因子と、その個体を育成する際に使う赤因子を分ける。親個体を作る場合、ツリー上の祖父母2人の完成時の赤因子を直接親の分として固定し、残る4人を配分。祖父母個体はさらに下の世代6人を提案する。1人★3以下・6人合計★18以下。空き枠は★3因子で提案し、親／祖父母／合計の内訳をツリーの各ウマに常時表示する。

開始時適性の上昇は同種赤★1・4・7・10で1〜4段階、上限A。ユーザー指定の手動周回基準として、バ場D・距離C（ダートD、マイルCを含む）を出走候補にする。これはゲーム自体の出走制限や自主トレ勝率ではない。完成時に指定する赤因子の対象適性Aも優先し、開始時Aが不可能な場合は育成中の追加継承が必要と明記する。育成中の適性上昇は確定として先取りしない。

## 共通GⅠの優先

親1×親2、親1×祖父母1、親1×祖父母2、親2×祖父母3、親2×祖父母4の5組について、共通GⅠの種類数×3を集計する。GⅡ以下と同じGⅠの重複勝利は加算しない。本育成本体が走るGⅠとの一致は、このボーナスの計算対象に含めない。予定全勝時の共通GⅠボーナスであり、キャラ固有の相性値やトレーナーアビリティを含む総相性値ではない。

目標・適性・赤因子6枠を制約とし、共通勝利を増やす重みで日程を探索。各個体の予定勝鞍を相手の探索へ戻して調整する。同じGⅠを別の年へ移し、同時期のマイルCSとジャパンCなどを両方揃える。3連戦を許容し、4連戦以上も共通GⅠが増える場合は含む。全組合せの厳密な最適解、勝利、スキルPt・評価点の最適性は保証しない。

## 画面

「因子厳選」タブは因子ツリーから開始。各ノードに「おすすめローテ」ボタンと育成用赤因子を表示。ローテはポップアップに年月・レース・予約／目標の区分を示し、コピー可能。全体のTXTにも6個体分を含める。継承・白因子／本育成のスキル／因子厳選のいずれも、件数・説明・集計・注意事項は結果末尾の「集計・補足・出典」へ移す。
