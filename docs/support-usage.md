# サポートカードの用途分類と本育成の固定枠

確認日：2026-10-19。対象：既存の全563枚、カードが持つ631スキル。

## 選択項目

- 距離・ダートの5項目：短距離、マイル、中距離、長距離、ダート。
- 脚質の4項目：逃げ、先行、差し、追込。

本育成の選択画面を開くと、選択中のコースの距離と作戦を反映する。ダート開催はダートも初期選択する。距離とダートは組み合わせ可能。同じ項目を再度押すとその条件を解除する。「全SSRを表示」で用途の絞り込みを解除し、「今回の条件に合わせる」で元に戻す。得意練習のフィルター、名前検索、最新順、本人・重複カードの除外は併用可能。

汎用は独立した選択項目にしない。対象に制限のないスキルを使えるカードは、選択した距離・脚質に自動で含める。ダートでも使える汎用カードをダート項目から除外しない。「ダートスキルあり」のカード表示は、限定スキルの所持を示す追加情報。

因子周回は初期状態では用途で絞らず、SR・Rも含む全カードを表示する。本育成の金スキル用途が合わないカードも、白スキルの周回元として選べる。

## 名前検索

育成ウマとサポカは、キャラ名のみを部分一致で検索する。本育成・因子周回・親と祖父母の選択画面で同じ照合を使う。ひらがな・カタカナ・半角カナ、英字の大文字・小文字、全角・半角の違いを吸収し、空白は無視する。例：エフフォーリアは「えふ」、トウカイテイオーは「ていおー」で検索できる。衣装名・カードのタイトルは画面に表示するが検索対象に含めない。距離・脚質・種類や併用制限による絞り込みは検索時も適用する。

## 分類の根拠

GameToraの公開スキルDBにある日本語説明の明示的な対象（例：`＜先行・中距離＞`）を距離・脚質・路面へ整理する。「前方」「後方」から脚質を推測せず、対戦相手への脚質デバフも育成キャラ自身の脚質制限とは扱わない。芝の条件は内部の照合には使うが、芝の選択項目は設けない。

本育成では金スキルを優先する。詳細が登録済みのイベントは、金スキルを取る択ごとの組み合わせを作り、その中の対象条件を交差させる。異なる択の距離と脚質を横断して組み合わせない。カード全体では、使える金スキルの択のいずれかが条件に合えば候補にする。金を取らない白スキルだけの択は本育成の用途を広げる根拠にしない。

詳細択が未登録の複数金スキルは、限定対象を優先する保守的な主用途分類。各金スキルを同時取得できるという説明ではない。対象が交わらない場合は個別の対象を残す。カードの展開欄で元の対象と、取得択の詳細が未登録であることを確認できる。「全SSRを表示」で用途分類を解除できる。金スキルがないカードは白ヒント・イベントスキルの対象を使う。

| カード | 表示する主用途 | 判断の根拠 |
| --- | --- | --- |
| 賢さフォーエバーヤング［Innovator］ | 全距離・汎用 | 尻尾の滝登り＋前人未到の汎用択がある。別にコール＆レスポンス＋イノベーションのダート択も持つ |
| スタミナメイショウドトウ［その執念は怒濤が如く］ | 中距離・長距離、汎用 | どの金択もパスファインダーを含む。先行コーナーの白イベントがあっても先行専用にはしない |
| 最新のスピードトウカイテイオー［天才的ユートピア］ | 全距離・先行 | 迸る気迫＋正々堂々を選べる。別択の夢の舞台へは中距離限定なので、長距離の自動択にはしない |

候補への表示は、スキルの対象条件に基づく主用途。ステータス上昇量、所持・凸数、レースでの強さ、加速の有効位置、必要回復量を順位付けしたものではない。カードを展開すると金スキル、登録済みの金択、所持ヒント、イベント白スキルとそれぞれの対象を確認できる。

## SSRたづなの固定

ユーザー指定に基づき、本育成の6枠目をSSR駿川たづな［一杯のノスタルジア］（ID 30305）の自前枠として固定。追加、リセット、旧保存やJSONの読み込みでも固定を適用する。選択・削除ボタンを設けず、同キャラの別カードも他枠には選べない。2026-10-21のユーザー指定により、サポカの自前・レンタル表記は画面とテキスト出力から外し、たづなの「固定」だけを表示する。継承ツリーの自前・フレンドの区分は維持する。

たづなが別枠にあった場合など、前5枠に空きができる場合は元の6枚目をそこへ移す。前5枠が全て埋まっている場合は6枚目を固定カードへ置き換える。保存プランの原本は書き換えない。2026-10-19のユーザー指定により、因子周回も6枠目に同じ固定を適用する。因子周回の他5枠はSR・Rも保持する。

## 種類アイコン

スピード、スタミナ、パワー、根性、賢さ、友人、グループのゲーム内アイコンを、全サポカ画像の右上に重ねる。キャラの顔アイコンには付けない。本育成の編成、カード選択、因子周回の編成に共通適用し、画像を同梱してオフラインでも表示する。
