# 本育成から因子周回を組む

## 本育成の判定

レース・作戦・本育成キャラ・本育成サポート6枚から取得経路を照合し、不足する白因子と継承固有の候補を先に表示する。全スキルの確認は「本育成のスキル」へ切り替える。継承固有の候補は全員を採用する意味ではなく、直接親は2人まで。

金スキルを含む詳細択があるイベントでは、その金択だけを本育成の候補にする。未指定の場合は開催条件・作戦の推奨スキルに合う金択を初期選択する。複数の金択がある場合は利用者が変更できる。金と引き換えになる白だけの択は本育成では使わない。金択のないイベントは、指定された択だけを計上する。

パワーSSRファインモーションでは以下を区別する。

| 用途 | イベント択 | 真髄・体の扱い |
| --- | --- | --- |
| 本育成 | かっとばせ！＋順風満帆 | このカードではカバーせず、不足因子に残す |
| 因子周回 | 気持ちを乗せて＋真髄・体＋陽の加護 | この周回で真髄・体の取得を狙える |

旧保存データで本育成に白択が入っていた場合は、その択を補正する。詳細未登録イベントは「要確認」として必要因子の画面にも残す。

## 因子から周回を開く

因子名または「因子周回の編成・優先スキルを見る」を押すと、独立した周回プランを開く。レース・作戦・本育成キャラ・対象因子ごとに保存する。

- 固有因子の場合は、固有を持つ衣装を周回キャラに固定する。継承進化自体を白因子として厳選する扱いにはしない。
- 白因子の場合は、コースの継承固有候補を周回キャラの初期候補にする。別の親・祖父母用キャラへ変更可能。本育成本人を周回親には選べない。
- 取得先となるサポートを選び、他の不足白因子もまとめて取得できるカードを6枠以内で提案する。
- 自前・ヒント・イベントと、排他的なイベント択を照合する。1回の周回で排他択の両方を同時に取れるとは扱わない。
- 真髄・体／力／速では、URAで対応するハッピーミークとの対決に成功する経路も選べる。URAを選んだ周回だけに計上する。
- 周回で取れる対象を、選択中の因子・優先度の順に表示する。この編成で不足するものは別枠に残し、別の編成案を開ける。
- 周回の「取得済み」は本育成の「準備済み」と別。因子化を確認してから本育成側で準備済みにする。

編成案の重みは取得経路をまとめるための編集上の重みで、ヒント率や因子化率の実測確率ではない。所持・凸数・レースボーナス・育成成績・相性・所要周回数は評価しない。自由枠が残った場合は、レースやスキルPtを考慮して利用者が追加できる。

JSONの旧形式は引き続き読み込める。新形式は本育成と周回プランをまとめて保存し、TXTにも現在の本育成に対応する保存済み周回編成・択を出力する。

## 画像

キャラ271衣装、サポカ563枚の画像を個別のIDに対応させ、選択画面・編成・周回案・継承元に表示する。取得元はGameToraの各詳細ページに掲載された画像。画像ファイルを同梱し、外部への画像リクエストに依存しない。
